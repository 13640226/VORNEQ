# Phase 0 — Component Playground Exit Criteria

## هدف

Component Playground باید قبل از شروع Home v1.0 به‌طور کامل تست شود.

## معیارهای PASS

- [ ] Light Theme
- [ ] Cream Theme
- [ ] Dark Theme
- [ ] RTL
- [ ] LTR
- [ ] Keyboard Tab Navigation
- [ ] Enter / Space Activation
- [ ] Focus Visible
- [ ] Mobile Layout
- [ ] Desktop Layout
- [ ] 200% Zoom
- [ ] prefers-reduced-motion
- [ ] Long Text Stress Test
- [ ] Disabled Controls
- [ ] Touch Targets >= 44x44px
- [ ] No horizontal overflow
- [ ] No broken local assets
- [ ] Privacy Scan PASS

## قواعد

P0 فقط زمانی PASS می‌شود که هیچ BLOCKER باقی نمانده باشد.

ISSUEهای غیرمسدودکننده باید قبل از ورود به Production ثبت شوند.

هیچ کد Home واقعی تا قبل از PASS شدن P0 نوشته نمی‌شود.
